広告と課金

広告も課金もありません。アクセス解析も使っていません。

ブラウザの中に残すもの

いちばん良い記録（何組にご満足いただけたか）、音のオン・オフ、ランキングの名前と ID、まだ送れていない記録を、お使いのブラウザの中（localStorage）に保存します。通信なしで遊べるよう、ゲームのファイルも手元に置きます。ブラウザのデータを消すと、これらも消えます。

ランキングに送るもの

記録を送るのは、ランキングに参加すると決めた人だけです。

  • 自分で決めた名前
  • ブラウザが作った、人を特定できない乱数の ID
  • ご満足いただけた組の数
  • 記録を確かめるための、その回のステージごとの記録（ステージの番号・グラスの形・ボトルの量・注いだ量）

名前と組の数はランキングでほかの人に見えます。ランキングの画面の「名前を変える」から「ランキングをやめて記録を消す」を選ぶと、名前と記録をサーバーから消せます。

ほかの人の名前を押して「この人を表示しない」や「通報する」を選ぶと、そのことをサーバーに残します（表示しない人をあなたの画面から外すため・運営が確かめるため）。ランキングをやめると、これも一緒に消えます。

ランキングの画面を開くと、参加していなくても、一覧を読むためにランキングのサーバーにつながります。ランキングのサーバーは Cloudflare を使っており、つながったときの IP アドレスを一時的に扱います（記録や名前を送るときの回数の制限にも使います）。

シェア

「結果をシェア」を押したときは、お使いの端末のシェアの画面（または X の投稿の画面）に、組の数とゲームの URL の文を渡します。こちらには何も送りません。

配信

ゲームは GitHub Pages から配信しています。アクセスの記録は GitHub が扱います。字体（しっぽり明朝・Cormorant Garamond）と 3D の部品（three.js）も、このゲームと同じ場所から配信しています。
